# Patient-derived lymphocytes drive smoldering lesion pathology in a chimeric multiple sclerosis mouse model

This repository contains the scripts used for the analyses in Perrot et al., 
*Patient-derived lymphocytes drive smoldering lesion pathology in a chimeric multiple sclerosis mouse model*.

The repository is organized into two directories, corresponding to the 
analysis approaches used in the study:

## Repository content

### 1. Single-nucleus RNA sequencing (`snRNAseq/`)

Contains the scripts used for single-nucleus RNA sequencing data processing, 
quality control, clustering, cell-type annotation, differential gene expression 
analysis and data visualization.

See [`snRNAseq/README.md`](snRNAseq/README.md) for a detailed description.

### 2. Multimodal analysis (`multimodal/`)

Contains the scripts used for the multimodal analysis.

See [`multimodal/README.md`](multimodal/README.md) for a detailed description.

## Data availability

The single-nucleus RNA sequencing dataset is available through the 
Gene Expression Omnibus (GEO) under the accession number 
[GSE351304](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE351304).
